# 演示录屏脚本（60 秒）

> 用途：GitHub README 顶部放 GIF、简历里放二维码链接、面试时现场播放。
> 工具：手机自带录屏（安卓/iPhone 都有），或 OBS。

---

## 录制前准备

1. 手机打开小程序，**提前加载一次**，让模型进缓存（录的时候就不会转圈太久）
2. 手机调成**深色主题**（默认暗夜最好看）
3. **关闭通知**（下拉控制中心 → 勿扰模式），避免录到微信消息
4. 横屏 / 竖屏都行，**竖屏更符合手机查看习惯**

---

## 分镜（60 秒）

| 时间 | 画面 | 旁白/字幕 |
|---|---|---|
| 0–5s | 打开小程序，停在列表页 | 「三维资产库 · 移动端 3D 预览」 |
| 5–12s | 手指滑动列表，展示卡片 | — |
| 12–20s | 点「破损头盔」进入预览页 | 「云端加载 GLB，1.18MB」 |
| 20–32s | **单指拖动旋转一圈**，再双指缩放 | 「单指旋转 · 双指缩放」 |
| 32–40s | 点右下角「分享这个模型」→ 选文件传输助手 | 「带参分享」 |
| 40–50s | 切到聊天，点开卡片，模型再次加载出来 | 「好友点开看到同一个模型」 |
| 50–56s | 返回首页，点右上角切换主题（暗夜→森林） | 「多主题，3D 背景同步切换」 |
| 56–60s | 点「+ 从聊天导入模型」选一个本地 glb | 「本地文件直接预览」 |

## 剪辑（可选，10 分钟）

- 用剪映：掐头去尾、加片头 1 秒黑底白字标题
- **导出 GIF**（给 GitHub README 用）：剪映导出 mp4 → 用 `ezgif.com` 转 GIF，控制在 **5MB 以内**
- 简历里放**视频二维码**而不是 GIF（用 `草料二维码` 把视频链接转成二维码）

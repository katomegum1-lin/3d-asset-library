## 一、已实现项的验证步骤

### P1-H · GLB 预检脚本

**验证**：

```bash
cd tools
node precheck.mjs --base "https://asset-demo-1536405020.cos.ap-guangzhou.myqcloud.com"
```

| 检查点 | 期望结果 |
|---|---|
| 非 GLB 文件 | 报「文件头不是 glTF」并拒绝 |
| 超过 8MB | 报「超过 8MB 上限」并拒绝 |
| Draco / meshopt 模型 | 报「解析失败 Missing required extension」并拒绝 |
| 正常模型 | 输出体积、面数、顶点数、贴图尺寸 |
| 输出文件 | 生成 `models.generated.json`，只含通过项 |
| 全部被拒时 | **不写文件**（避免生成空清单覆盖线上） |

**实测记录（2026-11-19）**：5 个文件中 3 个通过、2 个被拒（draco、meshopt 各一个）。

### P0-A · 性能埋点

**验证**：

1. 手机上打开真机调试
2. 进入「破损头盔」预览页
3. 看 vConsole 的 Log

期望输出一行：

```
[perf] OK model=helmet-safe assets=320ms ready=780ms total=790ms device=vivo V2463A sdk=3.18.0
```

| 场景 | 期望 |
|---|---|
| 加载成功 | `OK`，`ready` 有值 |
| 12 秒未就绪 | `FAIL reason=timeout` |
| 模型找不到 | `FAIL reason=model-not-found` |
| 取缓存 | vConsole 执行 `wx.getStorageSync('perfLogs')` 能看到数组，最多 30 条 |

**用途**：多次进入后统计 P50 / P90，写进 README。

## 二、未采纳项及原因

| 项 | 原因 |
|---|---|
| **D. 分享带 quality=hd\|ld** | 分享路径已改为指向首页（`/pages/index/index?...`），改回 `preview?id=` 会重新触发启动页渲染器未初始化的黑屏问题。且目前没有 hd/ld 两份资源，字段是空壳 |
| **C 的 hdUrl/ldUrl** | 只有一个版本的模型资源，加了无实际作用 |
| **E. 搜索筛选** | 当前仅 2 个模型，筛选器属于过度设计 |
| **F 的线框/网格开关** | XR-FRAME 未找到公开的 wireframe 相关属性，硬实现只能是伪造 |
| **G. 收藏/最近浏览** | 对简历无加分，优先级最低，暂不实现 |

## 三、通用回归检查（每次改动后跑）

| 检查 | 方法 |
|---|---|
| 列表页正常 | 编译后无黄条、卡片显示完整 |
| 预览页渲染 | 点头盔能出模型、能拖转 |
| 分享闭环 | 手机分享给文件传输助手 → 点开能加载 |
| 本地导入 | 从聊天选 .glb → 弹保存/不保存 → 能预览 |
| 本地删除 | 保存后点删除 → 确认 → 卡片消失 |
| 主题切换 | 切到暖白/森林，3D 背景色同步变 |
| 包体积 | 上传时源码包 < 2MB |
| 崩溃 | 真机跑一遍不闪退 |

## 四、上线前必查

- [ ] 小程序后台服务器域名：request + downloadFile 均已配置 COS 域名
- [ ] 主包 < 2MB
- [ ] 所有模型经 `precheck.mjs` 校验通过
- [ ] 真机（安卓 + iOS 各一台）验证通过
- [ ] 分享卡片在手机上可正常打开
- [ ] 无 `console.log` 泄露敏感信息
